# Data

Put `house_price_bd.csv` in this folder. It is not committed to the repository.

The file has 3,865 Bangladeshi property listings with these columns:

| Column | Example |
|---|---|
| `Title` | `2125 Square Feet Apartment For Sale In Bashundhara R-A` |
| `Bedrooms`, `Bathrooms` | `3.0` |
| `Floor_no` | `4` |
| `Occupancy_status` | `vacant` |
| `Floor_area` | `2125.0` (sq ft) |
| `City` | `dhaka`, `chattogram`, `narayanganj-city`, `gazipur`, `cumilla` |
| `Price_in_taka` | `৳39,000,000` |
| `Location` | `Block A, Bashundhara R-A` |
